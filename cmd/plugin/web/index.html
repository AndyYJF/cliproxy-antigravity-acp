当前支持范围

  • ✓
    普通文本聊天

    支持多轮历史、流式与非流式回复。

  • ✓
    请求取消

    客户端断开后，取消对应 ACP 会话。

  • ✓
    Codex CLI / Pi Agent

    支持 Responses 与 Chat Completions 的客户端工具调用、工具结果回传和连续多轮操作；工具在客户端运行。

  • ✓
    图片理解

    Chat Completions、Responses 与 Codex CLI 支持图片和多轮图片历史。接受 PNG、JPEG、WebP、GIF 的 Base64 或公开 HTTPS 地址；插件不限制图片张数；每张最多 8 MiB、合计最多 16 MiB，整个请求体最多 24 MiB。暂不支持音视频、文件上传、图片生成与托管搜索。

  • —
    高级生成参数

    ACP 不应用采样参数、token 上限、思考强度与结构化输出设置；客户端附带这些生成参数时会静默忽略。消息、工具和会话协议仍会校验。

ACP 不提供此适配器所需的精确 token 用量，因此页面不显示推测的用量或费用。
